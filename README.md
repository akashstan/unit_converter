# Unit Converter

A simple and efficient Unit Converter built with Python that performs accurate conversions between multiple unit categories through a user-friendly graphical interface.

## Features

- Length Conversion
- Weight/Mass Conversion
- Temperature Conversion
- Area Conversion
- Volume Conversion
- Speed Conversion
- Time Conversion
- Instant Results
- Input Validation
- Easy-to-use GUI

## Technologies Used

- Python 3

## Project Structure

```
Unit-Converter/
│── main.py
│── converter.py
│── README.md
│── requirements.txt
└── assets/
```

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/unit-converter.git
```

2. Navigate to the project folder

```bash
cd unit-converter
```

3. Run the application

```bash
python main.py
```

## Usage

1. Select the conversion category.
2. Choose the input and output units.
3. Enter the value.
4. Click **Convert** to view the result instantly.
